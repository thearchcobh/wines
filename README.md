# Madrid HHH Wine Run

Standalone single-page event site for the Madrid Hash House Harriers Wine Run.

## Confirmed event details
- €20 per person
- 9 wines
- 10 km Machos route
- 5 km Wimps / walkers route
- Pay on the day
- Limited spaces

## Still to add

The site is deliberately self-contained in `index.html` so it can be hosted anywhere as a static page.
